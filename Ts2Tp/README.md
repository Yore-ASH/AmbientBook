# Ts2Tp 原稿转换器

Ts2Tp 将没有逐字间隔的 UTF-8 `.tscps` 原稿转换成 `.tscp`。图形界面以事件表
显示全部对白、旁白和 `<s>/<c>/<p>` 控制语句；到达对白时按 Enter、Space 或
配置的按键记录每个字。ANSI 转义序列只用于样式显示，不占用计时项。

```powershell
python Ts2Tp/Main.py source/Scripts/plot.tscps
```

## 标点也计时

**所有可见字符都要按键**，标点和符号也不例外，所以逗号、句号都能有自己的停顿。
只有**空格**依旧立刻显示（0 秒），因为它没有自己的长度需要表演。

## 计时起点

「开始/重新计时」和「只录选中句」都只是**待命**：第一次按计时键才是计时
基准点。点按钮到第一次按键之间的犹豫时间不会被写进第一个字。

## 两种时钟模式

| 模式 | 基准点 | 句间停顿 |
| --- | --- | --- |
| 逐句模式（句间停顿不计入） | 每句重新取当前时刻 | **被丢弃**，每句首字延迟 ≈ 0 |
| 连续模式（句间停顿计入下一句） | 沿用上一个按键时刻 | 记进下一句第一个字的延迟 |

两者都只描述**时钟**行为。要「单次只设计一句话」，用下面的单句录制。

## 单句录制

在表格中选中一行对白，点「只录选中句」，就只有这一句需要按键，其余句保留
已有时间。每次录制完成后结果会立刻写回当前脚本，所以可以一句一句地补录，
然后随时保存。

打开已计时过的 `.tscp`（把它的内容当作原稿）即可继续局部修改；未计时的句子
在保存前会弹窗确认，未计时的行会以 0 秒写入。

## 音乐与每一句剧情强绑定

表格新增「音乐」列，事件标签也会显示，格式为 `简称 @ 偏移秒`，表示**这一句
开始播时音乐应该处在的位置**。偏移量按前面的句子时长和 `<s>` 等待累加得出，
所以重新录制任意一句后，后面所有句子的音乐位置会自动重算。

`<p>` 和 `<s>` 在计时期间会**真的执行**：

* `<p>简称` 解析 `Musics/__init__.json` 的 `CONFIG` 并播放；找不到音乐目录时
  按文件名直接查找。用「音乐文件夹」按钮可以手动指定目录。
* 重新声明**同一个**曲目不会重启播放，而是从当前位置续播 —— 这样逐句调试时
  每一句都从上一句结束的地方继续。换到不同曲目才从头开始，`<p>stop` 停止。
* `<s>秒数` 会真的等待；暂停期间的按键不计时，状态栏显示剩余时间。

> PyGame 只能对 OGG/MP3 做随机跳转，FLAC 无法 seek。因此这里的续播是
> **顺序续播**：曲目不会被重载，位置自然累积。要跳到任意一句的音乐位置，
> 需要把音乐转成 OGG。

## 完全预览

「完全预览」不是把事件列出来，而是**按设定好的程序流程把整个剧本真实播放
一遍**：每个字按录好的逐字延迟出现，`<p>` 真的换音乐，`<s>` 真的等待，`<c>`
真的清屏，角色名与颜色取自 `Scripts/__init__.json` 的 `NAME` 和 `STYLE`。
播放中按 **Esc** 停止（按钮会变成「停止预览」），播放期间按键不参与计时。

剧本还没有逐字时间时（例如刚写好的原稿），预览使用工具栏「预览逐字:」设置的
间隔，默认 0.06 秒，这样未计时的剧本也能看清节奏。

## 内容单页展示

按 `<c>` 分页并逐页列出文本。无 PySide6 时仍可使用 `Ts2Tp.model` 的转换和
键盘事件模型。
