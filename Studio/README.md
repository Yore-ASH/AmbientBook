# Studio 剧情工坊（桌面整合版）

**一个窗口走完全流程**：新建剧情包 → ① 创建角色 → ② 编写剧情并插入音乐 →
③ 逐字计时 → ④ 歌词 → ⑤ 导出 `.tscpkg` 并试播。

全程用结构化控件填写，**不需要打开任何裸文本编辑器**，也不用在几个工具之间来回
倒文件。以前分散在 `CharacterCreator` / `TSGenerator` / `Ts2Tp` / `PlotManager`
四处的步骤，现在都在左边这五步里。

```powershell
python -m pip install ".[gui]"
python Studio/Main.py
python Studio/Main.py source/dist/ExamplePlot.tscpkg
```

也可以在 `Editor/Main.py`（剧情制作工具箱）里点「剧情工坊」启动。

## 两种文件，各司其职

| 文件 | 是什么 |
| --- | --- |
| `.tscpkgs` | **工程文件**。跟 `.tscpkg` 结构完全一样，只多一个 `History/` 目录，每次保存都在同一个文件里记一版。编辑器默认用它。 |
| `.tscpkg` | **成品**。播放器认的就是它。「另存为」导出的就是这个——历史不会跟着走。 |

打开旧 `.tscpkg` 照常能编辑，但它不记历史（标题栏会显示 `[剧情包]` 而不是 `[工程]`）。
两种格式随时可以互转：新建时选哪个都行，`另存为` 永远产出干净的 `.tscpkg`。

## 五步分别做什么

### ① 角色

表格列出所有角色的**缩写 / 名字 / 样式**。双击或用「添加 / 编辑」打开一个对话框，
里面有颜色下拉、粗体、下划线，也可以直接填 `\033[33;1m` 这类 SGR，**输入时实时
预览**成播放器里的样子。

改缩写时会**自动把剧本里所有引用一起改掉**。删除角色前会检查还有没有剧本在用。

**批量添加…** 保留了原来角色生成器的批量流程：对话框不关，填一个按一次
「添加到列表」，右边累积成一张表，最后「全部添加」一次性提交。重复的缩写会**就地
更新**而不是新增，列表里会标「（更新）」。

另外三种导入方式：

| 按钮 | 从哪来 |
| --- | --- |
| 粘贴导入… | **两种格式都认**：JSON（下面那种）或 `缩写<TAB>全名<TAB>样式`。点「识别」可以先看解析结果 |
| 从 JSON 导入… | 一个 `Scripts/__init__.json`，或角色生成器导出的 `{"f": {"NAME": ...}}` |
| 从剧情包导入… | 另一个 `.tscpkg`／`.tscpkgs`／旧式剧情文件夹里的角色表 |
| 导出角色… | 存成 `.tscpc`，下次用「从 JSON 导入…」或直接粘贴取回 |

**粘贴框直接吃角色生成器复制出来的 JSON**，不用手工转格式：

```json
{
    "f": { "NAME": "FISH",   "STYLE": "\u001b[1;33m" },
    "b": { "NAME": "Bister", "STYLE": "\u001b[1;97m" },
    "I": { "NAME": "Iris",   "STYLE": "\u001b[1;36m" }
}
```

全部四种方式都是**合并**语义：同名的更新，新的追加。

### ② 剧情

上方选剧本（可新建 / 重命名 / 删除 / **导入剧本…**），下方是事件表：
**序号 / 类型 / 角色 / 内容**。

**导入剧本…** 同时接受 `.tscp`（编译稿，**连逐字时间一起带进来**）和 `.tscps`
（原稿，导入后到第 ③ 步录时间）。

九种操作全部用对话框完成：

| 按钮 | 填什么 |
| --- | --- |
| 添加对白 | 选角色 + 写台词（多行框） |
| 添加旁白 | 只写台词 |
| 添加暂停 | 秒数（数字框） |
| 清空屏幕 | 无参数 |
| 插入音乐 | 选已有曲目，或「插入新音乐…」现场选文件 |
| 编辑 | 按行类型打开对应的对话框 |
| 上移 / 下移 / 删除 | 调整顺序 |

**插入新音乐**时会依次问：音频文件 → `<p>` 简称 → 纯音乐还是带歌词 →（带歌词时）
现成 `.lrc` 还是 `lyrics.txt` + 现场录制 → 歌词颜色。和网页版问的问题完全一致。
音频直接写进剧情包，不需要事先准备什么目录结构。

双击任意一行即可编辑。**不会有 `[f]你好` 或 `<s>1.5` 这类格式出现在你面前。**

### ③ 计时

选剧本 → 选逐句/连续模式 → 点「开始 / 重新计时」或「只录选中句」，然后按计时键。
**第一次按键才是计时起点**，点按钮到第一次按键之间的犹豫不会被记进第一个字。

* 右边的预览面板会**逐字显示**，角色名带各自颜色，当前待录的字高亮
* `标点也计时`，只有空格自动显示
* `<p>` 真的播音乐（同一曲目续播不重启），`<s>` 真的等待，等待期间按键不计时
* 「只录选中句」只重录一行，其余行**保持原样**——没录过的仍然是「没录过」，
  不会被悄悄填成零延迟
* **导入时间…** 可以把一个已经录好的 `.tscp` 的时间搬过来。逐行**按位置和文字
  匹配**，文字不同的句子直接跳过并告诉你跳了几句，不会因为一句不一样就把后面
  全部错位

### ④ 歌词

左边是曲目表（简称 / 类型 / 文件 / 颜色），右边编辑选中曲目：

* 单选框切换**纯音乐 / 带歌词**
* 歌词框直接写 LRC（`[00:01.00]第一句`）
* **导入歌词文件…**：读一个 `.lrc`（直接用），或一个纯文本 `.txt`（载入后点录制）
* **录制每句时间…**：先在框里写好句子，点它 → 播放这首歌，**每按一次 Enter /
  Space 记录当前行的出现时间**，时间列还能双击手改
* **歌词颜色…** 取色器，色块实时显示

点「保存到剧情包」写入。带歌词的曲目在播放时会弹出歌词窗（汉字宋体、英文
Times New Roman 斜体）。

### ⑤ 导出

列出角色数、剧本数、音乐数、带歌词曲目数、逐字计时进度，并**指出还缺什么**：

* 剧本用到了没定义的角色
* 还没录完逐字时间的剧本
* 一个剧本都还没有

四个按钮：**保存到剧情包** / **另存为 .tscpkg**（导出干净副本，原工程继续编辑）/
**试播**（用现有播放器直接放这个包）/ **打开所在文件夹**。

**从已有剧情导入…** 把一个 `.tscpkg`／`.tscpkgs` 或旧式 `Musics`/`Scripts` 文件夹
**整个合并**进来：角色按缩写覆盖，剧本重名时自动加序号（`act.tscp` → `act2.tscp`）
不覆盖已有内容，音乐连歌词和颜色一起搬。搬不动的东西（比如音频文件丢了、标了带
歌词却没有 `.lrc`）会降级处理并在状态栏说明，不会让整次导入失败。

## 版本历史

用 `.tscpkgs` 新建工程时，**每次保存都会在同一份文件里记一版**，历史不散落在外面。

* ⑤ 导出页下方是**版本历史**表：版本号、时间、标签、规模（角色数／剧本数），最新在最上面
* 「保存为新版本…」给当前状态起个名字，之后随时能回来
* 没改动时重复保存**不会**堆版本（按内容哈希去重）；想强制留档就点「保存为新版本…」
* 双击一行或点「回溯到这个版本」即可回退。**当前内容不会被删**——回退后保存一次就是
  又一个新版本，等于双向可走
* 回退会一并恢复角色、剧本、音乐的类型／颜色／歌词；音频文件如果已经被删掉，会在
  状态栏列出哪几首没恢复
* 历史上限 200 版，超出后自动丢弃最旧的快照，工程文件不会无限膨胀
* **导出时历史不会跟着走**：`.tscpkg` 里只有当前状态，播放器完全不用知道历史的存在

## 界面

**「界面」菜单**可以切换 **浅色 / 深色**主题，选择会被记住，下次打开还是那个。

深色主题是这套样式；**播放剧情时的窗口完全不受影响** —— 样式表只作用于工坊窗口本身，
播放器是独立顶层窗口，既没有 Qt 父对象也不会继承调色板（这一点有测试守着）。

所有表格都是**紧凑**的：行高固定 22 px、隐藏行号槽、去掉多余网格线，所以上百句的
剧本也不会变成一片需要不断滚动的空白。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存到剧情包 |
| `Ctrl+Shift+S` | 另存为 `.tscpkg` |
| `Ctrl+N` / `Ctrl+O` | 新建 / 打开 |
| 计时键（默认 `Enter`） | 在 ③ 计时时记录当前字 |

菜单栏「文件」里有同样的条目，快捷键就写在旁边。

**每个步骤都能从源文件导入**：① 角色可批量添加或从 JSON／剧情包导入，② 可导入
`.tscp`/`.tscps` 剧本，③ 可从 `.tscp` 导入时间，④ 可导入 `.lrc`/`.txt` 歌词，
⑤ 可整个合并一个剧情包或文件夹。

## 工作方式

* 项目就是一个 `.tscpkg`（新建时先选位置）。角色和剧本**在内存里编辑，点保存才
  落盘**；音乐和歌词因为要嵌音频，插入时就直接写进容器。
* 标题栏会显示 `*` 表示有未保存改动；关窗或换文件时会问你要不要保存。
* 保存时会自动把延迟列表**补齐或截断**到「一个可见字符一个延迟」，所以改完台词
  之后即使时间对不上，也不会因此存不下去。

## 和旧工具的关系

| 原来 | 现在 |
| --- | --- |
| `CharacterCreator` 生成 JSON 片段再手工粘进 `__init__.json` | 「① 角色」直接写进剧情包 |
| `TSGenerator` 编辑 `.tscps` 文本 | 「② 剧情」用对话框填事件 |
| `PlotManager` 插入音乐 / 剧本 / 歌词 | 「② 剧情」「④ 歌词」内置 |
| `Ts2Tp` 逐字计时 | 「③ 计时」内置，同一套计时模型 |
| `TSCPEditor` 改已编译的 `.tscp` | 不需要了——内容始终以结构化形式编辑 |

旧工具**全部保留**，需要更细粒度的操作（比如直接手改 `.tscp` 文本、或把整个目录
打包）时仍然可以用。

## 代码结构

```text
Studio/
  model.py   StudioProject：角色 / 剧本 / 事件 / 音乐 / 歌词 / 汇总，不依赖 Qt
  Main.py    五个步骤页面 + 各种编辑对话框 + StudioWindow
```

`Studio/model.py` 不导入 Qt，所以整套流程逻辑可以脱离界面测试。
